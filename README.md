# ヘリ空輸時間検索

GitHub Pages用の静的Webツールです。

## 公開方法
1. このZIPを展開し、`index.html`、`style.css`、`data.js`、`app.js` をGitHubリポジトリ直下へアップロードします。
2. GitHubの **Settings > Pages** を開きます。
3. **Deploy from a branch** を選択し、`main` / `/ (root)` を指定して保存します。

## 集計仕様
- 機種別に集計。異なる機種は混合しません。
- 往路と復路は同一区間として統合します。
- 目安時間は中央値です。
- 仮想機番 1028 / 1017 / 1020 は除外済みです。
- 出発地と目的地が同一の便は除外済みです。
- 地点名の表記揺れは正規化しています。
- 十分な同一区間実績がある場合のみ、中央値から極端に乖離する明白な時間異常値を保守的に除外しています。

運航判断・飛行計画そのものには使用せず、最新の気象、航空情報、機体性能、運航規程等を確認してください。


## v2: 経由ルート推定
- 直行実績がない場合も、同一機種の実績区間をグラフとして接続し、最大3レグ（経由2地点）まで探索します。
- 推定時間は各レグの実績中央値の合計です。
- 最短推定時間順に最大3候補を表示します。
- 直行実績がある場合も参考として経由候補を表示できます。
- 給油・駐機等の地上時間は加算しません。
- 燃料・航続可否の判定は行いません。
